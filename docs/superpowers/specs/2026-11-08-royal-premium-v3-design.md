# Vanshawali 360 — Royal Premium Modern V3

## Intent
Refine the existing private, demo-only Multi-Vanshawali platform into a consistent, premium and accessible desktop/mobile experience. Preserve all existing screens, data and local demo interactions.

## Design direction
Retain emerald green, champagne gold, ivory and portrait imagery. Use a stronger visual hierarchy, softer elevated surfaces, clear focus styles, refined tree nodes, a meaningful mobile bottom navigation and responsive panel layouts.

## Scope
- Unified design tokens and component treatments for existing screens.
- Dashboard overview and Family Tree details polish.
- Mobile navigation and navigation ergonomics.
- No real authentication, backend connection, external messaging, or new personal data.

## Approaches
Royal Premium Modern was chosen over Luxury Minimal, because continuity with approved V1–V13 imagery is important.

## Verification
TypeScript, production build, and responsive browser smoke checks; continue using owner-private publication.
